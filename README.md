# 📊 Human Resource Dashboard

## 📌 Project Overview

![image alt](https://github.com/shriram-A-2004/HR-Dashboard-/blob/main/Screenshot%202026-06-04%20232324.png?raw=true)

![image alt](https://github.com/shriram-A-2004/HR-Dashboard-/blob/main/Screenshot%202026-06-04%20232543.png?raw=true)

This **HR Dashboard** was developed using **Tableau** to provide a comprehensive view of employee data and workforce insights. The dataset used for this project was generated using **Python Faker**, allowing realistic HR data simulation for analysis and dashboard creation.

The project consists of two dashboards:

* **Summary Dashboard** – Provides high-level HR insights through interactive charts and visualizations.
* **Employee Details Dashboard** – Displays detailed employee-level information in a tabular format.

---

## 🚀 Features

### 📈 Summary Dashboard

* Interactive charts for HR analysis.
* Hover functionality to explore hierarchical relationships:

  * Department → Job Title
  * Location → Employee Distribution
* Dynamic filters available in the top-right corner for customized analysis.
* Easy navigation to the Employee Details Dashboard using the **Details** icon.
* Provides quick insights into workforce composition and trends.

### 📋 Employee Details Dashboard

* Displays complete employee information.
* Filter section at the top for detailed exploration.
* Details icon allows seamless navigation between dashboards.
* Information button provides dashboard usage instructions.
* Export options:

  * PDF Download
  * Image Download

## 🧭 Dashboard Navigation

### 📈 Summary Dashboard

1. Explore HR metrics through interactive charts.
2. Hover over visualizations to view hierarchical data relationships.
3. Apply filters from the top-right corner.
4. Click the **Details** icon to access employee-level information.

### 📋 Employee Details Dashboard

1. View complete employee records.
2. Use filters to narrow down specific employees or departments.
3. Click the **Info** button for dashboard guidance.
4. Use the **PDF** or **Image** icons to export dashboard reports.
